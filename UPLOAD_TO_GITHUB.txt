КАК ЗАГРУЗИТЬ:
1. Распакуйте архив.
2. Откройте папку fd_finance_bot_github_upload_v2.
3. Выделите ВСЕ элементы внутри (Ctrl+A).
4. Перетащите их мышкой в окно GitHub Upload files.
5. Дождитесь окончания загрузки и нажмите Commit changes.

Папка app содержит код. Папки data и exports содержат видимые README.txt, поэтому GitHub их сохранит.
Не загружайте настоящий файл .env с токенами и API-ключами.
