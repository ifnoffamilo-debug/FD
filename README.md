# ФД Финансы — v2.1

Персональный Telegram-бот для рабочих и личных финансов с Groq.

## Основные разделы

- 🏭 Рабочие финансы — объекты, бюджеты, доходы/расходы, чеки, сравнение периодов.
- 👤 Личные финансы — доходы/расходы, автомобиль, долги, чеки, сравнение периодов.
- 🤖 Groq — умный ввод и анализ данных активного раздела.

## 💸 Долги

В личных финансах есть отдельная вкладка `💸 Долги`:
- `👤 Мне должны` и `💳 Я должен`;
- сумма, человек/контрагент, срок возврата, комментарий;
- частичные погашения;
- автоматический расчёт остатка;
- история погашений;
- редактирование активного долга;
- закрытие долга с подтверждением;
- после погашения бот предлагает добавить сумму в личные финансы как `Возврат долга` или `Погашение долга`;
- в сводке видны «Мне должны», «Я должен» и чистая позиция;
- просроченные долги отмечаются предупреждением.

## 🚗 Автомобиль: бензин + газ

При нажатии `⛽ Заправка` сначала выбирается:
- ⛽ Бензин;
- 🔵 Газ.

Для каждой заправки сохраняются сумма, литры, пробег, комментарий и при желании фото чека. Статистика показывает бензин и газ отдельно: расходы, литры и среднюю цену за литр, а также общие расходы на топливо и ₽/км при наличии данных пробега.

Старые заправки из v2.0 сохраняются и отображаются как `Не указано`, пока у них нет типа топлива.

## 📁 Объекты и бюджеты

- выбор объекта из сохранённого списка;
- создание объекта при добавлении операции;
- цена заказа/договора;
- плановый бюджет расходов;
- факт расходов и остаток бюджета;
- прибыль и предупреждение при использовании 90% бюджета;
- переименование и архив.

## 📷 Фото чеков

Оригиналы чеков сохраняются в `/data/receipts/YYYY/MM/`, а Telegram `file_id` — в базе. При Railway Volume на `/data` фотографии не пропадают после деплоя.

## 📈 Сравнение периодов

- текущий месяц ↔ прошлый;
- текущая неделя ↔ прошлая;
- текущий год ↔ прошлый.

## 📤 Excel

Выгрузка содержит листы:
- Рабочие финансы;
- Личные финансы;
- Объекты;
- Автомобили;
- Долги;
- Погашения долгов.

В операциях автомобиля дополнительно выгружаются тип топлива, литры и пробег.

## Обновление с v2.0

Базу удалять не нужно. При первом запуске v2.1 автоматически:
1. добавит поле `fuel_type` в существующую таблицу операций;
2. создаст таблицы долгов и погашений;
3. сохранит все старые операции, объекты, автомобили и чеки.

Railway Variables остаются прежними:

```env
BOT_TOKEN=ваш_токен_Telegram
ADMIN_IDS=ваш_Telegram_ID
AI_API_KEY=ваш_ключ_Groq
AI_BASE_URL=https://api.groq.com/openai/v1
AI_MODEL=llama-3.3-70b-versatile
DATABASE_PATH=/data/finance.db
TIMEZONE=Europe/Moscow
```

Start Command:

```text
python -m app.main
```

Railway Volume должен быть подключён к:

```text
/data
```

Не загружайте в GitHub настоящий `.env`, `finance.db` и папку с чеками.
