# ФД Финансы

Отдельный Telegram-бот для учёта доходов, расходов и прибыли мастерской. База этого бота никак не связана с рабочим ботом «Фабрика Деталей».

## Что работает

- ручное добавление доходов и расходов;
- категории операций;
- привязка операций к объектам;
- подтверждение перед сохранением;
- отчёты за сегодня, 7 дней, текущий месяц и всё время;
- прибыль и расходы по объекту;
- последние операции;
- выгрузка всей базы в Excel;
- доступ только по Telegram ID;
- журнал создания операций;
- умный ввод обычной фразой;
- вопросы Kimi по данным из финансовой базы.

## 1. Создание отдельного бота

1. Откройте в Telegram `@BotFather`.
2. Отправьте `/newbot`.
3. Задайте имя, например `ФД Финансы`.
4. Задайте username, который заканчивается на `bot`.
5. Скопируйте полученный токен.

## 2. Настройка Windows

1. Установите Python 3.11 или новее.
2. Распакуйте архив.
3. Запустите `run.bat` первый раз.
4. Скрипт создаст файл `.env` и остановится.
5. Откройте `.env` в Блокноте и заполните:

```env
BOT_TOKEN=токен_от_BotFather
ADMIN_IDS=ваш_telegram_id
AI_API_KEY=ключ_TokenRouter
AI_BASE_URL=https://api.tokenrouter.com/v1
AI_MODEL=moonshotai/kimi-k3-free
DATABASE_PATH=data/finance.db
TIMEZONE=Europe/Moscow
```

6. Снова запустите `run.bat`.

Команда `/myid` показывает Telegram ID даже пользователю без доступа. Добавьте нужные ID в `ADMIN_IDS` через запятую.

## 3. Kimi через TokenRouter

Kimi необязателен. Без ключа работают ручные операции, отчёты, объекты и Excel. Для подключения создайте ключ в TokenRouter в разделе **API Keys** и вставьте его в `AI_API_KEY`.

По умолчанию используется бесплатная модель `moonshotai/kimi-k3-free` через OpenAI-совместимый адрес `https://api.tokenrouter.com/v1`. Бесплатная модель может иметь ограничения по доступности и скорости.

## Примеры умного ввода

- `Купил металл за 38500 рублей для навеса в Репном`
- `Получил аванс 70000 за ворота Иванову`
- `Заплатил сотруднику 12000 за монтаж объекта гараж`

Перед записью бот всегда показывает распознанные поля и просит подтверждение.

## Где хранятся данные

База находится в `data/finance.db`. Для резервной копии достаточно остановить бота и скопировать этот файл.

Не отправляйте никому файл `.env`: в нём находятся секретные ключи.
