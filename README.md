# ФД Финансы — v2.0

Персональный Telegram-бот для рабочих и личных финансов с Groq.

## Что нового

### 🏭 Рабочие финансы / 👤 Личные финансы
- два независимых раздела;
- быстрый переключатель `🔄 Сменить раздел`;
- отдельные категории, отчёты, последние операции и аналитика Groq;
- при обновлении все старые операции автоматически относятся к рабочим финансам.

### 📁 Объекты и бюджет
- объект выбирается из сохранённого списка;
- можно создать новый объект прямо во время добавления операции;
- вариант `Без объекта`;
- цена заказа/договора;
- плановый бюджет расходов;
- факт расходов, полученные деньги, текущий результат, остаток бюджета;
- предупреждение при использовании 90% бюджета;
- переименование и архив объектов.

### 📷 Фото чеков
После сохранения расхода бот предлагает прикрепить фото.
- Telegram `file_id` записывается в базу;
- оригинал скачивается в `/data/receipts/YYYY/MM/`;
- чек можно открыть из карточки редактирования расхода;
- при Railway Volume `/data` фотографии сохраняются между перезапусками и обновлениями.

### 📈 Сравнение периодов
- текущий месяц ↔ прошлый;
- текущая неделя ↔ прошлая;
- текущий год ↔ прошлый;
- сравниваются доходы, расходы и результат в рублях и процентах.

### 🚗 Автомобиль
В личных финансах есть отдельный автомобильный раздел:
- несколько автомобилей;
- текущий пробег и история пробега;
- быстрая заправка: сумма, литры, пробег;
- ремонт/ТО/запчасти/шины/масла/мойка/страховка/налоги/парковка;
- фото чеков к автомобильным расходам;
- статистика за месяц, год и всё время;
- средняя цена топлива;
- стоимость эксплуатации ₽/км, если есть записи пробега;
- журнал расходов автомобиля;
- сервис по пробегу, например замена масла каждые 10 000 км.

### 🤖 Groq
- умный ввод обычным текстом;
- вопросы отдельно по рабочим и личным финансам;
- Groq видит бюджеты объектов или автомобильную статистику активного раздела;
- ручной учёт продолжает работать даже без AI_API_KEY.

## Безопасное обновление с v1.x

База удаляться не должна. v2.0 выполняет миграцию при первом запуске:
1. добавляет новые поля;
2. старым операциям ставит `finance_scope = work`;
3. создаёт справочник объектов из старых `object_name`;
4. сохраняет существующие ID и суммы операций.

Перед крупным обновлением всё равно рекомендуется скачать резервную копию Railway Volume или `finance.db`.

## Railway Variables

```env
BOT_TOKEN=ваш_токен_Telegram
ADMIN_IDS=ваш_Telegram_ID
AI_API_KEY=ваш_ключ_Groq
AI_BASE_URL=https://api.groq.com/openai/v1
AI_MODEL=llama-3.3-70b-versatile
DATABASE_PATH=/data/finance.db
TIMEZONE=Europe/Moscow
```

Start Command:

```text
python -m app.main
```

Для постоянного хранения базы и чеков подключите Railway Volume с Mount Path:

```text
/data
```

## Загрузка на GitHub

Загрузите содержимое этой папки в корень существующего репозитория с заменой старых файлов.

Не загружайте настоящий `.env`, `finance.db` и папку с чеками. Они исключены через `.gitignore`.
